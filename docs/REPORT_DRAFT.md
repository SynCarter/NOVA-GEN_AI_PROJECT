## 1. Problem Statement
Users often have to inspect CSV files manually, write code for simple calculations, and create charts before they can answer basic analytical questions. The project provides a conversational interface that converts common natural-language questions into verified dataframe operations and visual evidence.

**Success criteria:** the core test suite should pass; supported questions should map to the correct analytical operation; numerical answers should be generated by Pandas rather than invented by the language model.

## 2. Objectives and Scope
- Upload and profile CSV datasets.
- Answer common analytical questions in natural language.
- Support category-aware filtering.
- Generate interactive visualizations.
- Provide automated data-quality and insight summaries.
- Use a free local open-source language model for explanation.
- Keep numerical computation deterministic.

## 3. Solution and Features
NOVA combines a Streamlit interface, a deterministic Pandas analysis engine, Plotly visualizations and an optional local FLAN-T5-small model. The analysis engine identifies an operation and relevant column/filter, performs the calculation, and passes only the verified result to the explanation layer.

## 4. Tech Stack
| Technology | Purpose | Reason |
|---|---|---|
| Streamlit | Web interface | Python-first interactive app |
| Pandas | Data analysis | Deterministic dataframe operations |
| NumPy | Numeric support | Standard numerical operations |
| Plotly | Visualization | Interactive charts |
| Transformers | GenAI inference | Open-source model integration |
| FLAN-T5-small | Explanation | Small instruction-tuned open model |
| PyTorch | Model runtime | Local CPU inference |

## 5. Knowledge Base and Data
The application does not require a proprietary knowledge base. It operates on the CSV uploaded by the user. A sample sales dataset is included for demonstration and testing.

## 6. System Architecture
User → Streamlit UI → operation router → Pandas calculation → verified result → local LLM explanation → chart/table.

The key design choice is that numerical computation is performed before explanation, so the language model is not the source of truth for the numbers.

## 7. Implementation Highlights
1. Natural-language operation and filter detection.
2. Deterministic Pandas execution.
3. Local FLAN-T5 explanation with deterministic fallback.
